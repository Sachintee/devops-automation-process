Git Configuration Guide

This guide explains how to configure Git on your computer before working with GitHub repositories.

1. Check Git Installation

git --version

Example Output:

git version 2.50.1

2. Configure Username

git config --global user.name "Sachin Teenwal"

Verify:

git config --global user.name

3. Configure Email

git config --global user.email "your-email@example.com"

Verify:

git config --global user.email

4. Set Default Branch

git config --global init.defaultBranch main

5. Enable Colored Output

git config --global color.ui auto

6. Set VS Code as Default Editor

git config --global core.editor "code --wait"

7. View All Git Configurations

git config --global --list

8. Generate SSH Key

ssh-keygen -t ed25519 -C "your-email@example.com"

Start SSH Agent

eval "$(ssh-agent -s)"

Add SSH Key

ssh-add ~/.ssh/id_ed25519

Display Public Key

cat ~/.ssh/id_ed25519.pub

9. Test GitHub SSH Connection

ssh -T git@github.com

10. Clone Repository

git clone git@github.com:username/repository.git

11. Initialize New Repository

mkdir my-project
cd my-project
git init

Common Git Commands

Command Description
git status Check repository status
git add . Add all files
git commit -m "message" Create a commit
git push origin main Push code to GitHub
git pull origin main Download latest changes
git branch List branches
git checkout -b new-branch Create new branch
git merge branch-name Merge another branch
git log --oneline Show commit history
